# Bella Onojie Food App Website

## Project Description

This is a responsive three-page website created for the MTM6201 Advanced Web Design midterm assignment at Algonquin College.

The website is based on the Bella Onojie food app design and includes a Home page, Product page, and Contact page.

## Features

- Responsive layouts for desktop, tablet, and mobile
- Mobile hamburger navigation
- Food product cards
- Frequently Asked Questions section
- Contact form
- Responsive images

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
